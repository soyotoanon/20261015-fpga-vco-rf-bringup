DAC → DDS 同帧测试
==================

接线：
  RIGOL CH1 <- DAC 输出
  RIGOL CH2 <- DDS 第 8 路 RF 输出
  示波器 USB Device 或 LAN <- 电脑

使用：
  1. 在示波器上打开 CH1、CH2，手动调好量程、时基、触发，确保能稳定看到 100 MHz。
  2. 双击“启动DDS-DAC同帧测试.cmd”。
  3. 目标函数默认 y = 0.04x + 0.30；需要时直接改 k、b。
  4. 点“连接示波器”，再点“开始采集”。
  5. 程序每次生成一个新帧并冻结，然后从同一帧读取：CH1 VAVG、CH2 VPP/VRMS、CH2 频率。
  6. 点“停止”后可导出 CSV。

界面：
  - 主界面只保留目标 k、b 和连接/开始/停止。
  - VISA 地址、采样间隔、容差和 VPP/VRMS 放在“高级设置”。
  - 实测频率显示在结果区；若目标是 100 MHz 而显示约 50 MHz，应先检查 DDS 频率配置或参考时钟。

说明：
  - 程序不会修改示波器的量程、时基和触发设置。
  - 青线是目标函数，橙色虚线是实测拟合，白点是同帧采集数据。
  - 通过判据：至少 10 点、R² >= 0.99，拟合 k、b 相对误差均不超过界面填写的容差。
  - DS1102Z-E 模拟带宽为 100 MHz，正好处在本信号带宽边缘；若只关心“一次函数是否一致”，重点看 R²、斜率方向和相对变化。
