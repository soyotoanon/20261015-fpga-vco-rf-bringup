FPGA 输出信号驱动 VCO 产生 RF 信号：DAC 全量程扫描固件
=========================================================

目标板：ATK-DF7A35 V2.1（XC7A35T-2FGG484）
DAC：ACM9767 V1.3 / AD9767，双通道同步输出
系统时钟：50 MHz（R4）

烧写文件：bitstream\fpga_dac_vco_bringup.bit

烧写后自动循环：
1. 0x2000（中点，标称约 0 V）保持约 2.68 秒；
2. 从 0x0000 扫到 0x3FFF，16384 个码全部覆盖；
3. 每码保持 65536 个时钟，约 1.31072 ms；
4. 一次扫描约 21.4748 秒；
5. 扫完回 0x2000 保持约 2.68 秒，再重复。

Vivado 烧写：Hardware Manager -> Program Device -> Bitstream file，选择上面的 .bit。

重要：第一次只把 DAC CH1 接示波器，确认实际电压范围后再断电连接 VCO/DDS 模拟输入。
“VCO 输入可到 -5~+5 V”不自动等于“DDS 的 ADC/AIN/AM 调幅口也允许 -5~+5 V”。
若尚未确认目标模拟口的允许范围，请勿把全量程扫描直接送入该端口。
